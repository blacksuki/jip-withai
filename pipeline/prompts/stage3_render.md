1. スケルトンの <style> とタグ構造・クラス名・章立て(0〜5)は **一切変更しない**。
2. `{{ ... }}` プレースホルダを、2つのJSONの該当値で置換するだけ。
   - リスト系プレースホルダ（`{{...<li>}}` `{{...<tr>}}`）は該当タグを繰り返して埋める。
   - 修正項目群は changes 配列を回し、各要素を
     `<h3>` + `<h4>(1)変更前</h4><pre class="before">before</pre>`
     + `<h4>(2)変更後</h4><pre class="after">after</pre>`
     + 改善点の `<div class="box box-good">` で構成する。
   - コード中の < > & は &lt; &gt; &amp; にエスケープする。
3. 区分に応じ pill クラスを選ぶ: 不具合→pill-bad / 仕様・要確認→pill-warn。
4. 値が無い項目は無理に埋めず簡潔に空/該当なしとする。捏造しない。
5. 出力先パスに write する。完了後、出力パスを1行報告するのみ。
